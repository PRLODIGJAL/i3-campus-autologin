# 项目 i3 · 自动联网（校园网自动登录）

东莞理工学院校园网断线自动重连。装一次开机自启，之后掉线就自动登录，不用再管。

## 文件（都在「校园网自动登录」文件夹里）

| 文件 | 说明 |
|---|---|
| `autologin.py` | 核心脚本（Python） |
| `config.ini` | 账号配置（**模板，需填写自己的学号密码**） |
| `1-启动守护-有窗口.bat` | 手动启动守护（能看到运行状态） |
| `2-查看当前状态.bat` | 查看当前是否在线 |
| `3-安装开机自启.bat` | 装一次，以后开机自动跑 |
| `4-卸载开机自启.bat` | 不想用了就卸掉 |
| `5-抓取认证参数.bat` | 断网时抓认证参数（出问题才用） |

## 首次安装（3 步）

1. 打开 `config.ini`，填好学号和密码
2. 双击「3-安装开机自启.bat」
3. 双击「2-查看当前状态.bat」确认能连上

## 技术说明

- 认证方式：锐捷 RG-SAM+ / eportal
- 检测间隔：15 秒（config.ini 可调）
- 断网时用 IP 直连（172.31.252.91）发登录请求
- 仅限 Windows

⚠️ `config.ini` 含密码明文，不要把这个文件发给别人。仓库里的是空白模板。
